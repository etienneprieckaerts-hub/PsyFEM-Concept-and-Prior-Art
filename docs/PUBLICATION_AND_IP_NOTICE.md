# PsyFEM - Publication and IP Notice

**Publication status:** 2 June 2026

## Purpose

This repository is a curated public technical disclosure. It documents selected aspects
of the PsyFEM concept, its authorship and the bounded status of a private prototype. It
is not an open-source repository and does not publish the private implementation.

## Prior-Art Context

Public availability and a verifiable publication date can be relevant when assessing
prior art. Whether a particular document legally qualifies as prior art depends on the
applicable jurisdiction and on the content, accessibility, timing and sufficiency of the
disclosure.

This repository therefore does not claim that every public statement is
patent-defeating prior art. It also does not claim that publication preserves the
author's own future patent options in every jurisdiction.

## Copyright and Technical Ideas

Copyright can protect original written expression. It does not automatically protect
the underlying abstract ideas, systems, procedures or methods of operation described by
that expression.

This repository publishes enough information for professional technical orientation,
while intentionally withholding reproduction-critical implementation details. The
private source code, detailed algorithms, parameter values, data schemas, operational
artifacts and optimization recipes are not published.

## Practical Boundary

The public documents are intended to:

- establish a dated and attributable public record;
- explain the system at an architectural level;
- support informed professional interest and discussion;
- distinguish the prototype from several common market patterns; and
- preserve private implementation know-how.

They are not intended to:

- function as a build guide;
- provide a legal opinion on patentability or prior art;
- claim external validation, production certification or general benchmark
  superiority; or
- replace advice from a qualified IP professional.
